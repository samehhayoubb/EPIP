# Engineering Project Intelligence Platform

This folder contains documentation for the Engineering Project Intelligence
Platform (EPIP), a multidisciplinary platform for engineering and construction
project information and workflows.

## Product scope

EPIP is intended to support consultants and contractors across architecture,
electrical, and mechanical disciplines. Its planned capabilities include:

- Project and document management
- BOQ and invoice management
- Quantity surveying
- Technical submissions and review workflows
- An AI assistant for authorized project information
- Reporting and dashboards

The product definition is still evolving. Proposed capabilities and unresolved
decisions should not be treated as confirmed implementation requirements.
